Switches on a transmitter

On a RadioMaster, Jumper, Radiomaster-alike or any other EdgeTX radio, the sim only sees a switch if the radio is sending it. A fresh model mixes the four sticks and nothing else, so every switch is silent until you add it. Two ways, in Model → USB Joystick:

Advanced mode (EdgeTX 2.8 and later, on radios with 1 MB or more of flash) is the one to use. Set Mode to Advanced, then for each switch set its channel to SWEmu. Each switch position then arrives as its own button, with no mixer lines at all. Set the four stick channels to Normal so they stay axes.

Classic mode sends channels 1–8 as axes and channels 9–32 as buttons, so a switch needs a mixer line. Put each switch on a channel from 9 upward (Model → Mixes, add CH9 = SA, CH10 = SB, and so on) and it arrives as a button. A switch left on channels 1–8 arrives as an axis instead: that works too — record it and it gets one channel per position — but a 3-position switch on a channel above 8 only reads on/off, because a button has no middle.

Either way, unplug and replug the USB cable after changing the mode: the radio only tells the Chromebook what it has when it connects. Keep the RF module off while it is plugged in.
