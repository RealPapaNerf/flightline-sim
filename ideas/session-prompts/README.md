# Session prompts

Ready-to-paste context prompts for starting new Claude Code sessions on bigger pieces of
Flightline. Each one says what to read first, the goals in order, and how to check the work.

- [terrain-maps.md](terrain-maps.md): real terrain from lidar, the map format, the map builder, the maps repo
- [aircraft-builder.md](aircraft-builder.md): aircraft files, a generic plane model, the in-game builder
- [multiplayer.md](multiplayer.md): ghost racing, then live racing

Run them one at a time if you can. They all touch `src/app.js`, so parallel sessions will hit
merge conflicts.
